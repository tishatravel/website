## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Reference: `.specify/memory/constitution.md` (Travel Agency Website Constitution v1.0.0)

| Principle | Gate Question | Pass Criteria |
|-----------|---------------|---------------|
| I. Conversion-First | Does this feature support inquiry or booking conversion? | Clear conversion path identified; non-converting scope deferred or justified |
| II. Trust & Transparency | Does this feature strengthen or preserve visitor trust? | Company info, contact details, or social proof not degraded |
| III. Experience Consistency | Does this feature use the unified design system? | Reuses existing navigation, typography, colors, and interaction patterns |
| IV. Mobile-First Design | Is mobile the primary design target? | Layouts and interactions validated on mobile viewports first |
| V. Content Accuracy | Does this feature display or update travel content? | Content sources, update process, and accuracy checks defined |
| VI. Low-Friction Inquiry | Does this feature add or preserve inquiry paths? | Contact, quotation, or inquiry reachable in minimal steps |
| VII. Performance as a Feature | Will this feature impact page load or runtime? | Image optimization, script budget, and animation scope assessed |
| VIII. Accessibility | Are user-facing elements accessible? | Readable content, keyboard/screen-reader usability, and intuitive navigation planned |
| IX. Functional Visual Design | Does every visual element serve communication or conversion? | No decorative-only additions without functional rationale |
| X. Compelling Destination Presentation | Does this feature present destinations or packages? | Imagery, concise copy, and clear CTAs included |
| XI. SEO & Discoverability | Does this feature affect page structure or metadata? | Title, description, headings, and URL structure considered |
